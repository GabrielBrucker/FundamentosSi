## Aula 13 — Customer Relationship Management (CRM)

### O que é CRM
CRM (Customer Relationship Management) é a gestão do relacionamento com o cliente.  
É um conjunto de estratégias, práticas e tecnologias utilizadas para organizar, automatizar e melhorar o relacionamento entre empresas e clientes.

### Papel do CRM
- Organizar informações dos clientes
- Melhorar atendimento e comunicação
- Aumentar vendas
- Fidelizar clientes
- Automatizar processos comerciais
- Registrar histórico de interações

### Exemplos de CRM
- HubSpot
- Salesforce
- Pipedrive
- RD Station CRM
- Zoho CRM

## Aula 10 — Boas práticas de desenvolvimento de software em grupo/equipe

### Sistema de Versionamento de Código: Git + GitHub

#### Funções principais
- Controlar versões do código
- Criar backups do projeto
- Permitir trabalho em equipe
- Registrar alterações realizadas
- Facilitar colaboração entre desenvolvedores

### Sistema Kanban — Trello

#### O que é
Metodologia de gerenciamento de tarefas e atividades.

#### Origem
Criado pela Toyota utilizando cartões semelhantes a post-its.

#### Estrutura básica do Kanban
- TO DO → tarefas a fazer
- DOING → tarefas em andamento
- DONE → tarefas concluídas

### Atividade

#### Pesquisar:
- Diferença entre técnica e metodologia
- Como integrar Trello com GitHub

### Técnica versus Metodologia

#### Técnica
É a forma prática de executar uma tarefa específica.

#### Metodologia
É o conjunto organizado de métodos, regras e processos utilizados para atingir um objetivo.

### Integração Trello com GitHub

Existe integração entre Trello e GitHub.  
Ela permite:
- Vincular commits
- Relacionar pull requests
- Atualizar cartões automaticamente
- Acompanhar desenvolvimento do projeto

## Aula 9 — Internet das Coisas (IoT)

### Conceito
Internet das Coisas é a conexão de dispositivos à internet em qualquer lugar e momento.

### Características
- Dispositivos conectados
- Comunicação automática
- Compartilhamento de dados
- Automação de processos

### Sistemas Pervasivos versus Sistemas Ubíquos

#### Sistemas Pervasivos
Sistemas integrados ao ambiente que funcionam de forma contínua.

#### Sistemas Ubíquos
Sistemas acessíveis em qualquer lugar e momento.

### Destaques da IoT
- Automação residencial
- Automação comercial
- Automação industrial
