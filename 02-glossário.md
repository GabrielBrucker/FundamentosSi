 ## IaaS: 
 - Breve descrição: Fornece recursos de infraestrutura de TI virtuais e sob demanda — como servidores (máquinas virtuais)
 - Exemplo de mercado: Amazon Web Services 
 
 ## PaaS:
 - Breve descrição: Oferece um ambiente completo baseado na nuvem com ferramentas que permitem aos desenvolvedores criar, testar, implantar e editar
 - Exemplo de mercado: Heroku 
 
## SaaS: 
 - Breve descrição: Entrega aplicações de software prontas e prontas para uso via internet
 - Exemplo de mercado: Google Workspace 
 
## FaaS: 
- Breve descrição: É um subconjunto da computação serverless que permite aos desenvolvedores executar partes de código 
- Exemplo de mercado: AWS Lambda
 
## DaaS:
 - Breve descrição: Modelo de virtualização de desktop onde o provedor de nuvem hospeda a infraestrutura de desktops virtuais
- Exemplo de mercado: Microsoft Azure Virtual Desktop,

## DBaaS :
- Breve descrição: Banco de dados gerenciado em nuvem. O provedor de serviços cuida da configuração, manutenção, backups
- Exemplo de mercado: MongoDB Atlas

## SECaaS :
 - Breve descrição: Modelo onde provedores integram serviços de segurança na nuvem (como firewalls, detecção de intrusos, autenticação
 - Exemplo de mercado: Cloudflare
